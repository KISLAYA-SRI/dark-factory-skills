# Accessibility And I18n Compliance
- WCAG claims require evidence from semantics, keyboard/focus behavior, contrast, and automated/manual checks.
- Do not invent translations or claim certified compliance without supplied evidence.
- Locale-sensitive dates, numbers, currencies, and plurals must use locale-aware formatters.

## Regulatory Context
Use supplied controls only. Apply WCAG, privacy, security, identity, and compliance boundaries only when required by the skill scope.
